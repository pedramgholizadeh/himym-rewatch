بیانیه سلب مسئولیت

این وب‌سایت یک پروژه‌ی متن‌باز، غیرتجاری و صرفاً اطلاعاتی است که برای نمایش اطلاعات فیلم و سریال طراحی شده است. این سرویس هیچ فایل ویدیویی یا محتوای رسانه‌ای را میزبانی، ذخیره یا توزیع نمی‌کند و پخش محتوا از طریق منابع شخص ثالث انجام می‌شود.

ماهیت خدمات

این وب‌سایت صرفاً به‌عنوان یک واسط برای نمایش و سازمان‌دهی اطلاعات فیلم و سریال فعالیت می‌کند و هیچ‌گونه فایل ویدیویی یا محتوای رسانه‌ای را به‌صورت مستقیم میزبانی یا ذخیره‌سازی نمی‌کند.

داده‌های مورد استفاده از APIهای عمومی مانند The Movie Database (TMDb) و OMDb API دریافت می‌شوند. لینک‌های پخش و دانلود نیز بر اساس الگوهای از پیش تعیین‌شده و به‌صورت خودکار از سرویس‌های شخص ثالث — به‌ویژه الماس مووی — تولید می‌شوند.

این وب‌سایت هیچ کنترل، نظارت یا مسئولیتی نسبت به این لینک‌ها، سرورها یا محتوای ارائه‌شده توسط منابع خارجی ندارد. این منابع می‌توانند بدون اطلاع قبلی تغییر کنند، محدود شوند یا از دسترس خارج شوند.

نکات مهم

  • این پروژه کاملاً متن‌باز (Open Source) است و صرفاً با اهداف آموزشی توسعه یافته است.
  • این وب‌سایت هیچ‌گونه فضای ذخیره‌سازی یا سروری برای نگهداری و توزیع محتوای ویدیویی ندارد.
  • مسئولیت کامل نحوه‌ی استفاده از وب‌سایت بر عهده‌ی کاربران است و این سرویس هیچ مسئولیتی در قبال استفاده‌ی نادرست از خدمات ارائه‌شده نمی‌پذیرد.
  • کلیه‌ی حقوق محتوای نمایش‌داده‌شده متعلق به صاحبان اصلی آن است و این وب‌سایت هیچ قصدی برای نقض قوانین کپی‌رایت ندارد.
  • این پروژه یک نمونه‌ی آزمایشی برای یادگیری نحوه‌ی کار با APIها و توسعه‌ی وب است و هیچ هدف تجاری یا درآمدزایی ندارد.
  • این پروژه هیچ وابستگی رسمی به صاحبان حقوق محتوا یا سرویس‌های شخص ثالث ندارد.

سیاست‌نامه DMCA

ما به حقوق سازندگان محتوا و دارندگان حق کپی‌رایت احترام می‌گذاریم. این وب‌سایت صرفاً به‌عنوان یک جمع‌آوری‌کننده‌ی اطلاعات از APIهای عمومی فعالیت می‌کند و هیچ محتوایی را میزبانی نمی‌کند.

اگر شما صاحب اثر یا نماینده‌ی قانونی آن هستید و باور دارید لینک یا محتوایی در این وب‌سایت حقوق کپی‌رایت شما را نقض می‌کند، لطفاً اعلان حذف DMCA خود را همراه با اطلاعات زیر ارسال کنید:

  1. ۱اطلاعات تماس شما (نام، ایمیل و سازمان).
  2. ۲توضیح واضح از محتوای دارای حق کپی‌رایت.
  3. ۳لینک یا آدرس دقیق محتوایی که معتقدید ناقض کپی‌رایت شماست.
  4. ۴بیانیه‌ای مبنی بر اینکه با حسن نیت معتقدید استفاده از محتوای مورد نظر بدون اجازه‌ی شما، نماینده‌ی شما یا قانون، غیرمجاز است.
  5. ۵بیانیه‌ای تحت مجازات شهادت دروغ مبنی بر صحت اطلاعات ارائه‌شده و مجاز بودن شما برای اقدام از طرف صاحب کپی‌رایت.
