# HIMYM Rewatch

پلیر شخصی و فارسی برای ریواچ کردن *How I Met Your Mother* — هر ۹ فصل و ۲۱۱ قسمت، با کیفیت ۷۲۰p و ذخیره‌ی خودکار پیشرفت تماشا.

این پروژه برای طرفدارهای HIMYM ساخته شده که دلشون می‌خواد هر وقت هوس کرد، از همون‌جایی که ول کرده بودن ادامه بدن؛ بدون ثبت‌نام، بدون تبلیغ و بدون گشتن دنبال لینک.

## امکانات

- مرور کامل فصل‌ها و قسمت‌ها با نشان «در حال تماشا» و «دیده‌شده»
- پلیر سفارشی با پشتیبانی از MKV، انتخاب کیفیت/منبع، سرعت پخش، PiP و تمام‌صفحه
- ادامه‌ی خودکار از دقیقه‌ی ذخیره‌شده (`localStorage`)
- پخش خودکار قسمت بعد و علامت‌گذاری بالای ۹۰٪
- لینک مستقیم هر قسمت برای اشتراک‌گذاری (`#/s1/e1`)
- چیدمان RTL با کنترل‌های استاندارد LTR، ریسپانسیو برای موبایل
- کش کامل سایت با Service Worker؛ لودهای بعدی تقریباً آنی و قابل استفاده‌ی آفلاین

## قبل از هر چیز: VPN

لینک‌های ویدیو روی سرورهای ایران هستند. اگر VPN روشن باشد ویدیوها لود نمی‌شوند؛ برای همین هر بار که سایت باز شود یک هشدار نمایش داده می‌شود. اول VPN را خاموش کنید، بعد تماشا کنید.

## ساختار پروژه

| فایل | کاربرد |
| --- | --- |
| `index.html` | کل رابط کاربری و پلیر |
| `sw.js` | Service Worker برای کش کامل سایت |
| `how-i-met-your-mother.json` | داده‌ی فصل‌ها، قسمت‌ها و منابع |
| `assets/hero.jpg` | تصویر پس‌زمینه |
| `proxy.php` | پروکسی استریم MKV (روی `webiro.ir/api/proxy.php`) |
| `.github/workflows/deploy.yml` | انتشار خودکار روی GitHub Pages |

## پروکسی (مهم)

مرورگر برای پخش و seek داخل MKV به پاسخ `206 Partial Content`، هدر `Content-Range` و `Content-Type` ویدیو نیاز دارد. نسخه‌ی `proxy.php` داخل این ریپو این موارد را پاس می‌دهد و باید روی `https://webiro.ir/api/proxy.php` آپلود شود.

اگر پروکسی قدیمی باشد، ویدیو پخش می‌شود ولی عقب/جلو بردن و «ادامه از محل قطع» از کار می‌افتد. پروکسی فقط دامنه‌های `giftmond.ir` را می‌پذیرد؛ لیست در `ALLOWED_HOSTS` قابل تغییر است.

## انتشار خودکار

هر پوش روی شاخه‌ی `master` با GitHub Actions سایت را روی GitHub Pages منتشر می‌کند:

1. در ریپو → **Settings → Pages** → Source را روی **GitHub Actions** بگذارید (ورک‌فلو سعی می‌کند خودش فعالش کند، ولی اگر خطا داد این تنظیم دستی لازم است).
2. یک بار **Actions → Deploy to GitHub Pages → Run workflow** را بزنید یا تغییر جدیدی پوش کنید.
3. آدرس سایت: `https://pedramgholizadeh.github.io/himym-rewatch/`

ورک‌فلو قبل از انتشار، هش کامیت را داخل `sw.js` جای‌گذاری می‌کند تا نسخه‌ی کش مرورگرها با هر انتشار عوض شود و کاربران نسخه‌ی تازه را بگیرند.

## کش و سرعت

- بار اول: مرورگر سایت، JSON، تصویر و فایل‌های CDN (Tailwind و فونت وزیرمتن) را دانلود می‌کند و Service Worker آن‌ها را در Cache Storage نگه می‌دارد.
- بارهای بعد: HTML از کش می‌آید و در پس‌زمینه تازه‌سازی می‌شود؛ بقیه‌ی فایل‌ها cache-first هستند. یعنی صفحه بدون انتظار برای شبکه بالا می‌آید.
- ویدیوها و درخواست‌های پروکسی **هرگز** کش نمی‌شوند.
- برای تست محلی، اگر تغییری در `index.html` دیدید ولی اعمال نشد، در DevTools → Application → Service Workers روی **Unregister** بزنید یا کش‌ها را پاک کنید.

## اجرای محلی

```bash
php -S 127.0.0.1:8000
# http://localhost:8000 — proxy.php هم همین‌جا اجرا می‌شود
```

Service Worker فقط روی `localhost` یا HTTPS کار می‌کند.

## عیب‌یابی پخش

GitHub Pages فقط فایل استاتیک سرو می‌کند و PHP اجرا نمی‌کند؛ پس `proxy.php` باید جداگانه روی `https://webiro.ir/api/proxy.php` آپلود شود. نسخه‌ی جدید یک تست سلامت دارد:

```bash
curl "https://webiro.ir/api/proxy.php?ping=1"
# باید بدهد: {"ok":true,"version":"2"}
```

اگر به‌جای این JSON صفحه‌ی HTML یا خطا گرفتی، یعنی نسخه‌ی قدیمی پروکسی روی سرور است. فایل `proxy.php` همین ریپو (یا `https://pedramgholizadeh.github.io/himym-rewatch/proxy.php`) را دانلود کن و روی همان مسیر آپلود/بازنویسی کن.

تست هدر ویدیو (باید `206` و `video/x-matroska` باشد):

```bash
curl -sI -r 0-1023 "https://webiro.ir/api/proxy.php?url=<URL-encoded-episode-url>"
```

اگر مرورگر خطای `Format error` می‌دهد، پاسخ پروکسی `Content-Type: text/html` دارد و مرورگر به‌خاطر `nosniff` آن را رد می‌کند؛ پروکسی را دوباره آپلود کن.

## داده‌ی تماشا

- `himym.progress.v1` — ثانیه‌ی توقف هر قسمت و آخرین قسمت دیده‌شده
- `himym.prefs.v1` — صدا، سرعت و کیفیت انتخابی

همه‌چیز فقط در مرورگر خودتان ذخیره می‌شود و به هیچ سروری فرستاده نمی‌شود. با پاک کردن داده‌ی سایت، پیشرفت هم پاک می‌شود.

## پشتیبانی مرورگر

پخش MKV در Chrome، Edge و Firefox دسکتاپ تست شده است. Safari و iOS Safari کانتینر MKV را پشتیبانی نمی‌کنند و برای پخش به تبدیل سمت سرور (ffmpeg) نیاز دارند.
