# HIMYM Rewatch

پلیر شخصی و لوکالایز‌شده برای تماشای آنلاین *How I Met Your Mother* — همه‌ی ۹ فصل و ۲۱۱ قسمت، با ذخیره‌ی خودکار پیشرفت تماشا در مرورگر.

## ساختار

| فایل | کاربرد |
| --- | --- |
| `index.html` | کل سایت: مرور فصل‌ها، پلیر سفارشی، ذخیره‌ی پیشرفت |
| `how-i-met-your-mother.json` | داده‌ی فصل‌ها، قسمت‌ها و منابع ویدیو |
| `proxy.php` | پروکسی استریم MKV (روی `webiro.ir/api/proxy.php` می‌نشیند) |
| `assets/hero.jpg` | تصویر پس‌زمینه‌ی صفحه‌ی اصلی |
| `play.php` / `play.html` | نسخه‌ی قدیمی پلیر (بایگانی) |

## نکته‌ی مهم درباره‌ی پروکسی

مرورگرها برای پخش فایل‌های MKV به هدر `Content-Type` درست و پاسخ `206 Partial Content` نیاز دارند؛ وگرنه seek و «ادامه از محل قطع» کار نمی‌کند. نسخه‌ی اصلاح‌شده‌ی `proxy.php` در همین ریپو این دو مورد و همچنین `Content-Range` را درست پاس می‌دهد.

**بعد از هر تغییر، فایل `proxy.php` را دوباره روی `https://webiro.ir/api/proxy.php` آپلود کنید.** بدون این کار پخش انجام می‌شود ولی عقب/جلو بردن ویدیو و ادامه از دقیقه‌ی ذخیره‌شده از کار می‌افتد.

پروکسی فقط دامنه‌های `giftmond.ir` را قبول می‌کند؛ اگر منبع جدیدی اضافه شد، آرایه‌ی `ALLOWED_HOSTS` در بالای `proxy.php` را به‌روز کنید.

## اجرای محلی

```bash
python3 -m http.server 8000
# سپس http://localhost:8000
```

برای تست پروکسی به‌صورت محلی، `proxy.php` را با PHP سرو کنید (روی macOS سرور داخلی PHP تک‌رشته‌ای است و برای تست seek مناسب نیست).

## انتشار روی GitHub Pages

1. صفحات از شاخه‌ی `master` و ریشه‌ی ریپو منتشر می‌شوند (`.nojekyll` موجود است).
2. در تنظیمات ریپو → **Pages** → Source: **Deploy from a branch** → `master` / `/ (root)`.
3. آدرس نهایی: `https://pedramgholizadeh.github.io/himym-rewatch/`

## پیشرفت تماشا

پیشرفت در `localStorage` ذخیره می‌شود:

- `himym.progress.v1` — ثانیه‌ی توقف هر قسمت + آخرین قسمت
- `himym.prefs.v1` — صدا، سرعت پخش و کیفیت انتخابی

بعد از ۹۰٪ هر قسمت، آن قسمت «دیده‌شده» علامت می‌خورد و قسمت بعد به‌صورت خودکار پخش می‌شود.

## پشتیبانی مرورگر

پخش MKV در Chrome/Edge/Firefox دسکتاپ تست شده است. Safari و iOS Safari کانتینر MKV را پشتیبانی نمی‌کنند و نیاز به تبدیل سمت سرور (ffmpeg) دارند.
